# Third-Party Libraries and Tools

| Tool | Purpose |
|------|---------|
| Python | Backend development and machine learning pipeline |
| PyTorch | Executes ArcFace and SCRFD deep learning models |
| FastAPI | Provides REST APIs and WebSocket communication |
| Pydantic | Validates API requests, responses, and configuration data |
| Uvicorn | Runs the FastAPI backend server |
| InsightFace | Provides implementations of SCRFD and ArcFace |
| SCRFD | Detects faces and facial landmarks |
| ArcFace | Generates 512-dimensional face embeddings |
| OpenCV | Image preprocessing, alignment, and webcam processing |
| NumPy | Numerical operations and vector manipulation |
| scikit-learn | Computes evaluation metrics and threshold analysis |
| MaskTheFace | Generates synthetic masked face images during enrollment |
| RWMFD Masking | Produces additional synthetic mask variations |
| ChromaDB | Stores and performs similarity search on face embeddings |
| PostgreSQL | Stores identities, enrollments, metadata, and audit records |
| Next.js | Frontend web application framework |
| TypeScript | Provides type-safe frontend development |
